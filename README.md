## Dungeons & Dragons Dsahboard Application

This application uses the [Dungeons & Dragons Adventure Lookup API]https://adventurelookup.com/api and the [D&D 5th Edition API]https://www.dnd5eapi.co/ to visualize data about D&D monsters and prewritten adventure modules.

## Technologies used

- Vite + React
- Tailwind CSS
- Chart.js
- Axios

## To run

```
npm install
```

```
npm run dev
```
